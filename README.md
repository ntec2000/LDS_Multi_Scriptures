## 한국어

### 설치
**아이폰·아이패드**
1. 사파리에서 https://ntec2000.github.io/LDS_Multi_Scriptures/ 를 엽니다. (카카오톡 등에서는 ‘Safari로 열기’)
2. 화면이 모두 열릴 때까지 기다립니다. (처음 한 번 내장 경전 약 14MB 저장 — 와이파이 권장)
3. 공유 버튼 ⬆︎ → **홈 화면에 추가** → **추가**
4. 홈 화면의 **LDS 경전** 아이콘으로 실행합니다.

**안드로이드**
1. [최신 릴리스](https://github.com/ntec2000/LDS_Multi_Scriptures/releases/latest)의 Assets에서 `lds-scripture-v(버전).apk`를 내려받습니다.
2. APK를 눌러 설치합니다. (‘출처를 알 수 없는 앱’ 허용 필요)
3. 기존 앱이 있으면 덮어쓰기 업데이트되며 북마크·노트·형광펜·설정은 유지됩니다.

### 주요 기능
- 표준 경전(구약·신약·몰몬경·교리와 성약·값진 진주) 한·영 내장, 154개 언어 (교회 공식 번역)
- 주언어·보조언어 동시 표시 (짙은 남색 / 진한 갈색), 핀치 줌, 글꼴 9종, 테마
- 교회 자료실: 와서 나를 따르라, 리아호나 등 잡지, 교재, 연차 대회, 찬송가(가사·PDF 악보·음원), 영상
- 경전 안내서, 검색, 북마크·노트·형광펜, 기록
- 아이폰 웹 앱: 오프라인 실행(한·영 경전), 자동 업데이트

### 아이폰 웹 앱과 안드로이드 앱의 차이
- 아이폰은 처음 한 번 인터넷이 필요하고, 이후 한·영 경전은 오프라인으로 읽을 수 있습니다.
- 아이폰은 자동 업데이트, 안드로이드는 새 APK로 덮어쓰기 업데이트입니다.
- 아이폰에서는 찬송가 등 교회 페이지가 사파리 창으로 열립니다(‘완료’로 복귀).
- 아이폰 홈 화면 아이콘을 삭제하면 북마크·노트도 함께 삭제됩니다.

## English

### Install
**iPhone / iPad**
1. Open https://ntec2000.github.io/LDS_Multi_Scriptures/ in Safari. (In messaging apps, choose “Open in Safari”.)
2. Wait until it has fully loaded. (The first visit saves ~14 MB of built-in scriptures — Wi-Fi recommended.)
3. Share ⬆︎ → **Add to Home Screen** → **Add**
4. Launch it from the **LDS** icon on your Home Screen.

**Android**
1. Download `lds-scripture-v(version).apk` from Assets of the [latest release](https://github.com/ntec2000/LDS_Multi_Scriptures/releases/latest).
2. Tap the APK to install (allow “Install unknown apps”).
3. An existing installation is updated in place; bookmarks, notes, highlights and settings are kept.

### Features
- Standard works built in (Korean/English), 154 languages (official Church translations)
- Primary and secondary language together (deep navy / dark brown), pinch-zoom, 9 fonts, themes
- Gospel Library: Come, Follow Me, Liahona and other magazines, manuals, general conference, hymns (lyrics, PDF sheet music, audio), videos
- Guide to the Scriptures, search, bookmarks / notes / highlights, history
- iPhone web app: works offline (Korean/English scriptures), updates automatically
